When the berth is not ready,
what should the ship do?

A schedule recovery model for container liners, built on real Maersk schedules for the TP8 and TP7 transpacific services. An exact optimiser finds the cheapest recovery for a late vessel, and a machine-learning model learns to recommend the same decisions in milliseconds.

The optimiser: recover a late voyage

Set where the ship is and how late it is. The MILP finds the cheapest mix of sailing speed, port omission and faster berth handling over the next loop. It is compared with doing nothing and with a simple rule of thumb, using one shared cost model.

The learner: predict which ports to skip

The optimiser is exact but must be solved for every situation. An XGBoost model learns from thousands of optimiser answers, so it can recommend skips instantly. Real schedules contain only three omitted calls, so the training situations are sampled from the real patterns plus a synthetic year for the whole fleet. Ten models are compared.

How it is trained

  1. Sample thousands of situations from the real + synthetic delay and congestion patterns
  2. Solve each one exactly with the MILP
  3. Learn which calls the MILP omits: ten models, from logistic regression to XGBoost
  4. Advise: fix the skips, let a small MILP set the speeds

Where the training data comes from

Synthetic

The real files hold 6 ships over 5 months. One full year is simulated for the whole fleet, using the real delay, berth-congestion, speed-recovery and port-stay patterns. The real data itself is left untouched.
